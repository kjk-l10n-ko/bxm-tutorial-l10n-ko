게임: Barrage Musical ~Basic Danmaku Tutorial~ (弹幕音乐绘 基础教学篇). 동방 프로젝트 풍 탄막 슈팅의 기초를 가르치는 튜토리얼 게임. 강사는 "광선검 요정" 친칠라(ChinChilla) 한 명이고, 대사는 모두 친칠라가 플레이어에게 하는 강의다. 영어 원문을 기준으로 번역하고, 주석의 중국어 원문은 뉘앙스 확인용으로만 본다.

[말투]
1. 친칠라의 대사(story/*): 밝고 친절한 선생님의 해요체 (~해요 / ~이에요 / ~하세요 / ~죠?). 반말·합니다체를 섞지 않는다. 장난스러운 감탄("자, 봐요!", "어때요, 작죠?")은 살린다.
2. 메뉴·설명·UI·스테이지 설명(dll/*, scene, loctext): 짧은 명사구 또는 합니다체. 스테이지 제목은 명사구 (예: "랜덤탄 소개").
3. 크레딧(scene, credits 주석): 직함만 번역하고 사람 이름·팀 이름은 원문 그대로 둔다.

[문장 품질]
- 번역투를 피한다: "~에 의해", "~하는 것이다", "~의" 연쇄. 한국 슈팅 게임 커뮤니티에서 쓰는 자연스러운 용어로 쓴다.
- 의미를 줄이거나 바꾸지 않는다. 키 이름(Left Shift, Z, X), 수치, 스테이지 번호(A-1, B-9)는 그대로 둔다.
- 한 Conversation 이 한 번에 화면에 표시된다. 원문이 줄바꿈(\n)을 가지면 같은 위치에 줄바꿈을 둔다. 문장이 두 항목에 걸쳐 이어지면(원문이 쉼표로 끝나는 등) 한국어도 다음 항목으로 자연스럽게 이어지게 한다.
- `<size=+12>`, `<color=...>`, `</size>` 같은 TMP 태그는 그대로 보존한다.

[용어]
- danmaku → 탄막, bullet hell → 탄막 슈팅, shmup / shooting game → 슈팅 게임
- hitbox → 피격 판정 (짧게 쓸 때 "판정"), area of collision → 충돌 범위
- focus (slow movement) → 저속 이동, graze → 그레이즈, bomb → 봄, spell card → 스펠 카드
- aimed shot / player-aimed → 조준탄, odd-numbered / even-numbered shots → 홀수탄 / 짝수탄
- randomized shot → 랜덤탄, fixed shot → 고정탄, laser → 레이저, barrage → 탄막
- streaming → 흘리기, tapping → 끊어 피하기 (원문이 이 개념을 쓸 때)
- ChinChilla → 친칠라, Lightsaber Fairy → 광선검 요정, Beryl → 베릴
